How a round runs

a new round opens the moment the last one closes

  1. Open

    Six bugs are drawn from real Python repositories. Miners see practice bugs from the same codebases; the scored ones stay hidden behind a published commitment.

  2. Window 2 hours

    Strategies are uploaded privately and signed with a hotkey registered on SN74. Each miner's pull request carries only the signed commitment.

  3. Evaluate

    Every strategy and the no-strategy baseline run the same agent and model on the same hidden bugs, each episode in a sealed sandbox.

  4. Crown

    The best gain over the baseline on this round's bugs wins, if it is above zero. On a tie the reigning king keeps the crown.

  5. Publish

    Hidden bugs, salts, scores and every losing strategy are published. The king's fully verified runs become open training data.

Compete

from practice bugs to a sealed entry

  1. See this round's practice bugs. One per hidden bug the round is scored on.
    python -m sh.cli.miner tasks
  2. Write the strategy. A SOUL.md on fixing bugs in those codebases, plus skills/<name>/SKILL.md if you want. Prose only.
  3. Submit privately. This lints the bundle, signs it for the round, uploads it to the submission server and opens your one pull request, which carries only the signed commitment.
    uv run python -m sh.cli.miner submit --bundle DIR --key HOTKEY --checkout . --head-owner YOU
  4. Race on the live board. When the window closes the round is sealed and evaluated. The king's pull request is merged, and the merge is what the reward follows.
  5. Defend the crown. A king defends every round, but a round it wins pays only through a defense pull request: run submit again in that window with the crowned bundle unchanged.

Check every result

nothing here has to be taken on trust

When a round opens it publishes its practice bugs, its window and a digest of the hidden bugs. When it closes it publishes the hidden bugs, close.json, crown.json, reveal.json with every withheld half and its salt, and the scorecards.

HMAC(salt, withheld) must equal each task's commitment, and the crown recomputes from the published episodes.

Every strategy that leaves the competition is published under rounds/<id>/revealed/, where it hashes to the digest its pull request committed to. The king's stays private until it is dethroned.

Payment pools the last 8 rounds, so consistency pays. The crown is each round's alone.
