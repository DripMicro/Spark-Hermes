How a round runs

the next round opens as soon as one closes

  1. Open

    6 hidden bugs from real Python repos, with practice bugs to study

  2. Window 2 hours

    Strategies are uploaded privately, each PR holds only a signed commitment

  3. Evaluate

    Every strategy and the baseline run on the same bugs in a sealed sandbox

  4. Crown

    The best gain over the baseline wins, a tie keeps the king

  5. Publish

    Bugs, scores and losing strategies go public, the king's runs become training data
