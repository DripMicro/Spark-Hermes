Compete

one round, start to finish

  1. See the round's bugs. python -m sh.cli.miner tasks lists the open round's practice bugs, one per hidden bug it is scored on.
  2. Write the strategy. A SOUL.md on fixing bugs in those codebases, plus skills/<name>/SKILL.md if you want. Prose only.
  3. Submit privately. uv run python -m sh.cli.miner submit --bundle DIR --key HOTKEY --checkout . --head-owner YOU lints, signs for the round, uploads the bundle to the submission server and opens your one PR, which carries only the signed commitment. The hotkey must be registered on SN74.
  4. The race. When the window closes every strategy is sealed and evaluated. The best against the baseline is crowned and its PR merged; the merge is what the reward follows. Every bundle now out of the competition is published.
  5. Defend the crown. A king defends every round, but a round it wins pays only through a defense PR: run submit again in that window with the crowned bundle unchanged.

Each round publishes its practice bugs, window and a digest of the hidden bugs when it opens, and the hidden bugs, close.json, crown.json, reveal.json (every withheld half and salt) and scorecards when it closes. HMAC(salt, withheld) must equal each task's commitment, and the crown recomputes from the published episodes.

Every bundle that leaves the competition is published under rounds/<id>/revealed/ at the close, where it hashes to the digest its PR committed to. The king's stays private until it is dethroned.

Payment pools the last 8 rounds, so consistency pays. The crown is each round's alone.
